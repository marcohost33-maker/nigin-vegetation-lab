Ein generatives Botanik-Labor: **Wiese** und **Kornfeld** auf 1, 24 oder 216 Sechsecken (1 Sechseck = 1 m²). Drei Darstellungen stehen zur Wahl: die **Bildstudie** (stehende Bildtafeln, im Browser gezeichnet), **3D live** mit prozeduralen Halmen und Ähren, die ein zusammenhängendes Windfeld über die Hexgrenzen bewegt, und eine **2.5D-Windszene**. Das Licht lässt sich in 3D auf Morgen, Tag oder Abend stellen (nicht in der Bildstudie).

## So startest du

1. **Direkt im Browser:** oben auf *Im Browser spielen* klicken. Fertig.
2. **Offline:** *HTML herunterladen*, dann die Datei mit Chrome, Edge, Firefox oder Safari öffnen. Es ist keine Installation nötig, nur JavaScript muss aktiv sein.
   - Auf iPhone und iPad zeigt die Vorschau der Dateien-App kein JavaScript. Die Datei dort über *Teilen* in einem Browser öffnen.

## Bedienung

- **Ziehen** Kamera drehen · **Mausrad** Zoom · **Doppelklick** zurücksetzen
- Windrichtung und -stärke einstellen (wirkt in 3D und 2.5D)

## Was es ist und was (noch) nicht

- Alle Bilder und Texturen erzeugt das Programm selbst (Code); es sind keine Fotos, keine KI-Bilder und keine Felddaten eingebettet. Die **Bildstudie** ist eine stilisierte Tafel, kein fotorealistisches Bild.
- Der Wind ist qualitativ, nicht in m/s gemessen; 3D ist Beta und braucht WebGL2.

## Datenschutz

- Die Welt läuft vollständig lokal; die Datei lädt nichts nach und baut von sich aus keine Netzwerkverbindungen auf.
- Beim Spielen über *Im Browser spielen* liefert GitHub Pages die Datei aus und verarbeitet dabei, wie jeder Webserver, Zugriffsdaten (etwa die IP-Adresse). Mit der heruntergeladenen Datei entfällt auch das.
- Es wird nichts im Browser gespeichert.
- Keine Konten, keine Cookies, keine Analyse oder Werbung.
